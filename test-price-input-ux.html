🎯 Улучшения UX поля ввода цены

❌ Проблемы в старой версии
  • Курсор скачет - из-за toFixed(2) в value
  • Стрелочки залезают - на второй знак после запятой
  • Узкое поле - w-32 (128px) мало для комфортного ввода
  • Стрелочки отвлекают - ненужные элементы управления
✅ Решения в новой версии
  • Стабильный курсор - убран toFixed(2) из value
  • Больше места - увеличена ширина до w-40 (160px)
  • Отступ справа - pr-6 для размещения стрелочек
  • Скрыты стрелочки - через CSS appearance: textfield
