📋 Ожидаемое поведение

Запрос должен отправляться на:

GET /v1/pos/schedule/prices/{station_number}?system={network_number}&dt=2025-09-01T00:00:00

В консоли должны появиться логи:

📅 Загрузка журнала цен { networkId: "15", stationId: "bto-azs-4", startDate: "2025-09-01T00:00:00" } 🗂️ STS API: getPriceSchedule called { networkNumber: "15", stationNumber: "bto-azs-4", startDate: "2025-09-01T00:00:00" } ✅ STS API: Журнал цен получен { type: "object", isArray: false, data: {...} } 📊 STS API: Обрабатываем данные { count: X, sample: [...] }
⚠️ Возможные проблемы
  • STS API не настроен - проверьте настройки в /settings/external-database
  • Нет токена - метод refreshTokenIfNeeded должен получить токен
  • Неправильные параметры - проверьте external_id сети и станции
  • Сетевая ошибка - проверьте доступность STS API
