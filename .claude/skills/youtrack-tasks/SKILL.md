# YouTrack Tasks - legacy

## Статус

YouTrack больше не является текущим рабочим трекером задач TradeFrame / TradeControl.

Текущий трекер задач - Plane self-hosted: `https://plan.dataworker.ru`, проект TradeFrame.

## Как использовать

- Новые задачи, баги, приемку и приоритеты вести только в Plane.
- YouTrack использовать только для чтения старых ссылок, восстановления исторического контекста или миграции задач в Plane.
- Не переносить старые YouTrack-команды в новые workflow и документацию.
- Не сохранять токены YouTrack или Plane в репозиторий.
