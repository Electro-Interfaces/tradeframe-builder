# Русский код и документация

## Основные правила

### 1. Комментарии в коде
- Всегда пишите комментарии на **РУССКОМ** языке
- Комментарии должны объяснять "почему", а не "что"
- Избегайте очевидных комментариев

```typescript
// ✅ Хорошо - объясняет почему
// Кэшируем результат, так как запрос к API занимает 2-3 секунды
const cachedData = useMemo(() => fetchData(), []);

// ❌ Плохо - очевидно из кода
// Получаем данные
const data = fetchData();
```

### 2. Git коммиты
- Сообщения коммитов на **РУССКОМ** языке
- Формат: `тип(область): описание`
- Типы: `feat`, `fix`, `refactor`, `docs`, `style`, `test`, `chore`

```bash
# ✅ Хорошо
git commit -m "feat(auth): добавлена двухфакторная аутентификация"
git commit -m "fix(tanks): исправлен расчет уровня топлива"

# ❌ Плохо
git commit -m "fix bug"
git commit -m "update"
```

### 3. Документация
- README, CHANGELOG, документы - на **РУССКОМ**
- Markdown файлы с правильной структурой заголовков
- Примеры кода с русскими комментариями

### 4. Переменные и функции
- Имена переменных и функций на **АНГЛИЙСКОМ** (camelCase, PascalCase)
- JSDoc комментарии на **РУССКОМ**

```typescript
/**
 * Получает данные о резервуарах для указанной станции
 * @param stationId - Идентификатор станции
 * @returns Массив данных резервуаров
 */
async function getTankData(stationId: string): Promise<Tank[]> {
  // Проверяем валидность ID станции
  if (!stationId) {
    throw new Error('ID станции не может быть пустым');
  }
  return await api.getTanks(stationId);
}
```

### 5. Сообщения об ошибках
- Пользовательские сообщения на **РУССКОМ**
- Технические логи могут быть на английском

```typescript
// Для пользователя
toast.error('Не удалось загрузить данные. Попробуйте позже.');

// Для разработчика (в консоль при отладке)
console.error('Failed to fetch data:', error);
```

## Что НЕ делать

- ❌ Писать комментарии на английском
- ❌ Делать коммиты с сообщениями типа "fix", "update", "changes"
- ❌ Оставлять код без комментариев в сложных местах
- ❌ Использовать транслит (например, "poluchit dannye")
- ❌ Добавлять `console.log()` в production код (запрещено по CLAUDE.md)
