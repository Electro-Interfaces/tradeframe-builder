# Plane Tasks для TradeFrame

## Статус

Plane - текущий рабочий трекер задач TradeFrame / TradeControl.

YouTrack - legacy-источник. Новые задачи TradeFrame в YouTrack не заводить.

## Конфигурация

- URL: `https://plan.dataworker.ru`
- Тип: self-hosted Plane
- Проект: TradeFrame
- Язык задач и комментариев: русский

## Правила работы

- Все новые задачи, баги, приемку и приоритеты фиксировать в Plane.
- В задаче указывать контекст, ожидаемый результат, критерии приемки и ссылки на PR/коммиты.
- Статус задачи обновлять в Plane по факту работы.
- Если встречается старая ссылка `TF-*` из YouTrack, использовать ее только как исторический контекст и переносить актуальную работу в Plane.
- Не хранить Plane API token, cookies, персональные ключи и другие секреты в репозитории, документации, коммитах или memory.

## Автоматизация

Если нужна работа через API, использовать локальный/global Plane skill или защищенные переменные окружения. Не добавлять токены и внутренние секреты в этот репозиторий.

При создании или обновлении задач с кириллицей использовать безопасный способ передачи JSON через файл или локальный helper, чтобы не ломать кодировку.
