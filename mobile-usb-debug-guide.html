📱 USB Debugging Setup для TradeControl

Руководство по настройке USB отладки для анализа проблем загрузки на мобильных устройствах.

🤖 Android - USB Debugging

Шаг 1: Включить режим разработчика

  1. Откройте Настройки → О телефоне
  2. Нажмите на "Номер сборки" 7 раз подряд
  3. Появится сообщение "Вы стали разработчиком!"

Шаг 2: Включить USB отладку

  1. Откройте Настройки → Система → Дополнительно → Для разработчиков
  2. Включите "Отладка по USB"
  3. Включите "Остаться активным" (экран не будет выключаться при зарядке)

Шаг 3: Подключить к компьютеру

  1. Подключите телефон USB-кабелем к компьютеру
  2. На телефоне выберите "Передача файлов" или "USB для отладки"
  3. Разрешите отладку по USB при появлении запроса

🍎 iOS - Web Inspector

Шаг 1: Включить Web Inspector

  1. Откройте Настройки → Safari → Дополнения
  2. Включите "Web Inspector"

Шаг 2: Настроить Mac (если используете)

  1. На Mac откройте Safari
  2. В меню Safari → Настройки → Дополнения
  3. Включите "Показать меню «Разработка»"

Шаг 3: Подключиться

  1. Подключите iPhone к Mac через USB
  2. Доверьтесь компьютеру на iPhone
  3. В Safari на Mac: Разработка → [Ваш iPhone] → TradeControl

🔍 Chrome DevTools для Android

Подключение через Chrome

  1. Откройте Chrome на компьютере
  2. Перейдите на chrome://inspect
  3. Убедитесь, что включен "Discover USB devices"
  4. Ваш телефон должен появиться в списке
  5. Нажмите "Inspect" рядом с TradeControl
chrome://inspect/#devices

Что искать в Console

  • 🔄 [Xs] HTML загружен - HTML страница загрузилась
  • 📱 main.tsx starting... - Начало загрузки React
  • 📱 React imported - React успешно импортирован
  • 📱 App imported - Компонент App импортирован
  • 📱 CSS imported - Стили загружены
  • 📱 Creating React root... - Создание React root
  • 📱 App rendered successfully! - Приложение отрендерилось

🛠️ Альтернативный способ - Длинная диагностика

Если USB отладка недоступна, мы можем создать версию с долгой диагностикой:

// Увеличить время показа каждого этапа до 3 секунд // Добавить паузы между этапами загрузки // Сохранять диагностику в localStorage // Показать полный лог в интерфейсе

Этот режим замедлит загрузку, но позволит увидеть каждый шаг.

📊 Собираемая диагностическая информация

Технические данные

  • User Agent: Тип и версия браузера
  • Viewport: Размер экрана устройства
  • Memory: Доступная память
  • Connection: Тип сетевого соединения
  • Performance: Время загрузки каждого этапа

Ошибки загрузки

  • JavaScript Errors: Синтаксические и логические ошибки
  • Network Errors: Проблемы загрузки ресурсов
  • React Errors: Проблемы рендеринга компонентов
  • Service Worker: Проблемы PWA

⚠️ Возможные проблемы

Частые причины темного экрана на мобильных:

  • Memory Limits: Недостаточно памяти для загрузки больших JS файлов
  • CSP Issues: Content Security Policy блокирует скрипты
  • Service Worker: Конфликты кеширования
  • Touch Events: Проблемы с touch-action и overscroll-behavior
  • Viewport: Неправильная настройка viewport метатега

🚀 Quick Start

  1. Подключите Android-устройство по USB
  2. Откройте chrome://inspect в Chrome
  3. Найдите ваше устройство и нажмите "Inspect"
  4. Откройте https://electro-interfaces.github.io/tradeframe-builder/ на телефоне
  5. В DevTools перейдите на вкладку Console
  6. Обновите страницу и следите за логами загрузки
