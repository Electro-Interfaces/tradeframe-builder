🔧 Инициализация правовых документов

Проблема

Ошибка при сохранении черновика
Причина: В таблице document_types нет записей о типах документов (tos, privacy, pdn).
Решение: Выполните SQL скрипт ниже в Supabase SQL Editor.

1. SQL скрипт для Supabase

Скопируйте и выполните этот SQL в Supabase SQL Editor:

Открыть Supabase Dashboard
-- Инициализация типов правовых документов INSERT INTO document_types (code, title, description, is_active, created_at, updated_at) VALUES ('tos', 'Пользовательское соглашение', 'Terms of Service - условия использования сервиса', true, NOW(), NOW()), ('privacy', 'Политика конфиденциальности', 'Privacy Policy - правила обработки персональных данных', true, NOW(), NOW()), ('pdn', 'Политика защиты персональных данных', 'Положение о защите персональных данных (ПДн)', true, NOW(), NOW()) ON CONFLICT (code) DO UPDATE SET title = EXCLUDED.title, description = EXCLUDED.description, is_active = EXCLUDED.is_active, updated_at = NOW(); -- Проверка результата SELECT * FROM document_types WHERE is_active = true ORDER BY code;
