🚀 Применение миграции audit_log

Этот инструмент поможет применить SQL миграцию для создания таблицы журнала аудита в Supabase.

Шаг 1: Проверка подключения

Проверим подключение к Supabase и наличие таблицы audit_log.

Шаг 2: Применение миграции

После проверки вы можете применить миграцию двумя способами:

Вариант А: Через Supabase SQL Editor (рекомендуется)

  1. Откройте Supabase SQL Editor
  2. Создайте новый запрос
  3. Скопируйте SQL из файла migrations/create-audit-log-table.sql
  4. Вставьте в редактор и нажмите Run (Ctrl+Enter)

Вариант Б: Автоматически через PostgREST

⚠️ Экспериментальный метод. Может не работать из-за ограничений PostgREST.

Шаг 3: Проверка результата

После применения миграции проверим, что таблица создана корректно.

Шаг 4: Тестовая запись

Создадим тестовую запись в журнале аудита.
