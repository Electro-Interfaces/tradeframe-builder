📋 Инструкция по проверке в TradeFrame
  1. Откройте страницу цен в TradeFrame
  2. Нажмите "Изменить цены"
  3. Выберите дату, например: 24.09.2025 00:00
  4. Откройте консоль (F12)
  5. Нажмите "Установить цены"
  6. Найдите лог "🕐 Дата для API (локальное время)"
  7. Убедитесь, что дата соответствует выбранной: "2025-09-24T00:00:00"
