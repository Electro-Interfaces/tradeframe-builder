# Plane - трекер задач TradeFrame

Дата актуализации: 2026-04-24

## Статус

Plane - текущий рабочий трекер задач TradeFrame / TradeControl.

YouTrack, встречающийся в старых документах, является legacy-источником. Новые задачи TradeFrame в YouTrack не заводить.

## Основная информация

| Параметр | Значение |
| --- | --- |
| URL | `https://plan.dataworker.ru` |
| Тип | self-hosted Plane |
| Проект | TradeFrame |
| Назначение | задачи разработки, баги, приемка, приоритеты, сопровождение |

## Правила работы

- Все новые задачи, баги и доработки оформлять в Plane.
- По каждой задаче фиксировать контекст, ожидаемый результат, критерии приемки и ссылки на связанные PR/коммиты.
- Статусы и исполнителей обновлять в Plane по мере работы, не держать актуальный статус только в переписке.
- Решения по scope, приоритетам и приемке фиксировать в комментариях задачи.
- Исторические ссылки на YouTrack переносить в Plane при продолжении работы по такой задаче.

## Для AI-агентов

- Перед работой читать `README.md`, `docs/HANDOVER.md`, `docs/DOCS_STATUS.md` и этот файл.
- Для задач TradeFrame считать Plane единственным текущим трекером.
- YouTrack использовать только для чтения исторических ссылок, если это явно требуется.
- Не записывать Plane API token, cookies, персональные ключи и другие секреты в репозиторий, документацию, коммиты или Knowledge Graph.
- Для автоматизации использовать защищенные переменные окружения или локальные/global skills, где секреты хранятся вне проекта.

## Что не хранить в репозитории

- Plane API tokens.
- Cookies/session data.
- Личные логины и пароли.
- Экспорты задач с персональными данными или закрытыми коммерческими деталями без согласования.
