# Руководство по CronBuilder

## Обзор

**CronBuilder** - улучшенный интерфейс для настройки cron-выражений с интуитивными подсказками, примерами и валидацией в реальном времени.

## ✨ Ключевые возможности

### 1. **Быстрый выбор из готовых шаблонов** 🎯

10 наиболее популярных вариантов расписания в виде кнопок:

| Иконка | Шаблон | Cron | Описание |
|--------|--------|------|----------|
| 🕐 | Каждый час | `0 */1 * * *` | Проверка каждый час |
| 🕑 | Каждые 2 часа | `0 */2 * * *` | Проверка каждые 2 часа |
| 🕓 | Каждые 4 часа | `0 */4 * * *` | Проверка каждые 4 часа |
| 🕕 | Каждые 6 часов | `0 */6 * * *` | Проверка каждые 6 часов |
| 🕛 | Каждые 12 часов | `0 */12 * * *` | Проверка каждые 12 часов |
| 📅 | Ежедневно в 9:00 | `0 9 * * *` | Каждый день в 9 утра |
| 📆 | Понедельники 9:00 | `0 9 * * 1` | Каждый понедельник в 9:00 |
| ⏰ | В 9:00 и 18:00 | `0 9,18 * * *` | Дважды в день |
| 🗓️ | 1-го числа 00:00 | `0 0 1 * *` | Первый день месяца |
| ⏱️ | Каждые 30 минут | `*/30 * * * *` | Каждые полчаса |

### 2. **Ручной ввод с валидацией** ✅

- **Поле ввода** с моноширинным шрифтом для удобства
- **Валидация в реальном времени** с индикаторами:
  - ✅ Зелёная галочка - корректное выражение
  - ❌ Красный крестик - ошибка
- **Автоматическая расшифровка** введённого cron:
  - `0 */6 * * *` → "Каждые 6 часов"
  - `0 9 * * 1` → "По понедельник в 09:00"

### 3. **Интерактивные подсказки** 💡

#### Структура cron-выражения
```
M  H  D  M  W
│  │  │  │  └─ День недели (0-6, 0=Вс)
│  │  │  └──── Месяц (1-12)
│  │  └─────── День месяца (1-31)
│  └────────── Час (0-23)
└───────────── Минута (0-59)
```

#### Специальные символы
- **`*`** - любое значение
- **`*/N`** - каждые N единиц (например: `*/6` = каждые 6)
- **`A,B`** - список значений (например: `9,12,18`)
- **`A-B`** - диапазон (например: `9-17`)

### 4. **Примеры использования** 📚

Встроенные примеры с пояснениями:

```
0 */6 * * *      → Каждые 6 часов
0 9 * * *        → Ежедневно в 9:00
0 9 * * 1        → По понедельникам в 9:00
0 9,18 * * *     → В 9:00 и 18:00
*/30 * * * *     → Каждые 30 минут
0 9-17 * * 1-5   → Раб. дни 9:00-17:00
```

## 💻 Использование в коде

### Интеграция в форму

```tsx
import { CronBuilder } from '@/components/notifications/CronBuilder';

function MyForm() {
  const [cron, setCron] = useState('0 */6 * * *');
  const [description, setDescription] = useState('');

  return (
    <CronBuilder
      value={cron}
      onChange={(cronExpression, humanReadable) => {
        setCron(cronExpression);
        setDescription(humanReadable);
      }}
    />
  );
}
```

## ⚙️ Технические детали

### Валидация

Компонент использует `isValidCron()` из `scheduleFormatter.ts`:

```typescript
// Проверяет:
- Количество полей (должно быть 5)
- Диапазоны значений:
  - Минуты: 0-59
  - Часы: 0-23
  - День месяца: 1-31
  - Месяц: 1-12
  - День недели: 0-6
- Корректность специальных символов (*/N, A,B, A-B)
```

### Расшифровка cron

Функция `cronToHumanReadable()` распознаёт паттерны:

```typescript
'0 */N * * *'     → "Каждые N часов"
'0 H * * *'       → "Ежедневно в HH:00"
'0 H * * D'       → "По [день недели] в HH:00"
'0 H1,H2 * * *'   → "В HH:00, HH:00"
'*/M * * * *'     → "Каждые M минут"
'0 H1-H2 * * *'   → "С HH:00 до HH:00"
```

## 🐛 Обработка ошибок

### Типичные ошибки и подсказки

| Ввод | Ошибка | Подсказка |
|------|--------|-----------|
| `0 25 * * *` | Час > 23 | "Час должен быть 0-23" |
| `60 * * * *` | Минута > 59 | "Минута должна быть 0-59" |
| `* * 32 * *` | День > 31 | "День должен быть 1-31" |
| `* * * 13 *` | Месяц > 12 | "Месяц должен быть 1-12" |
| `* * * * 7` | День нед. > 6 | "День недели 0-6 (0=Вс)" |
