# Руководство по использованию ScheduleEditor

## Обзор

`ScheduleEditor` - это человекоориентированный компонент для настройки расписания проверок уведомлений. Он преобразует сложные cron-выражения в понятный визуальный интерфейс.

## Возможности

### 🎯 Типы расписания

1. **Каждые N часов** (`hourly`)
   - Выбор интервала: 1, 2, 3, 4, 6, 8, 12, 24 часа
   - Пример: "Каждые 6 часов" → `0 */6 * * *`

2. **Ежедневно в заданное время** (`daily`)
   - Выбор конкретного времени через time picker
   - Пример: "Ежедневно в 9:00" → `0 9 * * *`

3. **Еженедельно в заданный день** (`weekly`)
   - Выбор дня недели (пн-вс)
   - Выбор времени
   - Пример: "По понедельникам в 9:00" → `0 9 * * 1`

4. **Несколько раз в день** (`custom_time`)
   - Добавление нескольких временных меток
   - Пример: "В 09:00, 18:00" → `0 9,18 * * *`

### 📋 Готовые шаблоны

Компонент предлагает 7 готовых шаблонов:
- Каждый час (`0 */1 * * *`)
- Каждые 2 часа (`0 */2 * * *`)
- Каждые 4 часа (`0 */4 * * *`)
- Каждые 6 часов (`0 */6 * * *`)
- Каждые 12 часов (`0 */12 * * *`)
- Ежедневно в 9:00 (`0 9 * * *`)
- По понедельникам в 9:00 (`0 9 * * 1`)
- 1-го числа в полночь (`0 0 1 * *`)

## Интеграция

### Использование в форме

```tsx
import { ScheduleEditor } from '@/components/notifications/ScheduleEditor';

// В компоненте формы
<ScheduleEditor
  value={cronExpression}
  onChange={(cron, humanReadable) => {
    // cron - техническое выражение для backend
    // humanReadable - описание для пользователя
    setSchedule({ cron, description: humanReadable });
  }}
/>
```

### Отображение расписания

```tsx
import { cronToHumanReadable } from '@/utils/scheduleFormatter';

// Преобразование cron в читаемый текст
const description = cronToHumanReadable('0 */6 * * *');
// => "Каждые 6 часов"
```

## Архитектура

### Компоненты

1. **ScheduleEditor** (`src/components/notifications/ScheduleEditor.tsx`)
   - Визуальный редактор расписания
   - Автоматическая генерация cron-выражений
   - Парсинг существующих cron-выражений

2. **scheduleFormatter** (`src/utils/scheduleFormatter.ts`)
   - `cronToHumanReadable()` - преобразование cron → текст
   - `getScheduleShortDescription()` - короткие описания
   - `isValidCron()` - валидация cron-выражений

### Интеграция с RuleDialog

`RuleDialog` использует `ScheduleEditor` вместо ручного ввода cron:

```tsx
// Старый способ (убран)
<Input
  placeholder="0 */6 * * *"
  className="font-mono"
/>

// Новый способ
<ScheduleEditor
  value={form.watch('cronExpression')}
  onChange={(cron, description) => {
    form.setValue('cronExpression', cron);
    form.setValue('scheduleDescription', description);
  }}
/>
```

## Преимущества новой системы

### ✅ До (старая система)

- ❌ Пользователь вводит cron вручную
- ❌ Легко допустить ошибку в синтаксисе
- ❌ Нужно знать формат cron
- ❌ Неудобно для нетехнических пользователей

**Пример:**
```
Cron выражение: [0 */6 * * *]
Формат: минута час день месяц день_недели
```

### ✅ После (новая система)

- ✅ Визуальный выбор параметров
- ✅ Автоматическая генерация cron
- ✅ Понятные описания на русском языке
- ✅ Готовые шаблоны для типовых случаев
- ✅ Предпросмотр результата

**Пример:**
```
Тип расписания: [Каждые N часов ▼]
Интервал в часах: [Каждые 6 часов ▼]

Расписание: Каждые 6 часов
Cron выражение: 0 */6 * * *
```

## Технические детали

### Формат внутреннего состояния

```typescript
interface ScheduleConfig {
  type: 'hourly' | 'daily' | 'weekly' | 'custom_time';

  // Для hourly
  everyNHours?: number;

  // Для daily
  dailyTime?: string; // "HH:mm"

  // Для weekly
  weekday?: number; // 0-6 (вс-сб)
  weeklyTime?: string; // "HH:mm"

  // Для custom_time
  customTimes?: string[]; // ["09:00", "18:00"]
}
```

### Парсинг cron-выражений

Компонент автоматически распознает типы расписания:

```typescript
// Hourly: "0 */6 * * *"
parseCronExpression('0 */6 * * *')
// => { type: 'hourly', everyNHours: 6 }

// Daily: "0 9 * * *"
parseCronExpression('0 9 * * *')
// => { type: 'daily', dailyTime: '09:00' }

// Weekly: "0 9 * * 1"
parseCronExpression('0 9 * * 1')
// => { type: 'weekly', weekday: 1, weeklyTime: '09:00' }

// Custom times: "0 9,18 * * *"
parseCronExpression('0 9,18 * * *')
// => { type: 'custom_time', customTimes: ['09:00', '18:00'] }
```

## Валидация

Модуль `scheduleFormatter` включает валидацию:

```typescript
import { isValidCron } from '@/utils/scheduleFormatter';

isValidCron('0 */6 * * *');  // true
isValidCron('0 25 * * *');   // false (час > 23)
isValidCron('invalid');      // false
```

## Будущие улучшения

Возможные расширения функциональности:

1. **Диапазоны времени**

2. **Рабочие дни**

4. **Временные зоны**
