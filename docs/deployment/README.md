# Deployment Docs

Главный актуальный документ: `DEPLOYMENT.md`.

| Файл | Статус |
| --- | --- |
| `DEPLOYMENT.md` | актуальный штатный деплой через GitHub Actions |
| `DEPLOYMENT_GUIDE.md` | частично актуально, сверять с `DEPLOYMENT.md` |
| `PRODUCTION_DEPLOYMENT_CHECKLIST.md` | частично актуально, использовать как чеклист с проверкой портов/секретов |
| `DEPLOYMENT_HISTORY.md` | история |

Legacy-деплой находится в `../_archive/deployment-legacy/` и не является текущей инструкцией.
