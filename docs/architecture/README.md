# Architecture Docs

Главный актуальный документ по архитектуре находится выше: `../ARCHITECTURE_CURRENT.md`.

Файлы в этом разделе являются тематическими справками. Перед использованием сверять с кодом:

| Файл | Статус |
| --- | --- |
| `API_AUTHENTICATION.md` | частично актуально, полезно для двухуровневой auth-схемы |
| `API_INTEGRATION.md` | требует ревизии, есть legacy-описания |
| `STS_API_REFERENCE.md` | справочник STS, сверять с proxy и Swagger |
| `NOTIFICATION_SYSTEM.md` | сверять с `server/services/notification*` |
| `REMEMBER_ME_FEATURE.md` | исторический документ |
| `ALTERNATIVE_CHARTS_PROPOSALS.md` | исторические предложения |
