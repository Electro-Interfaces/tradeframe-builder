# Корректировка остатков нефтепродуктов по результатам инвентаризации

## Документ для согласования с заказчиком

Дата: 2026-04-30
Подготовил: ElsyPlus / TradeFrame
Получатель: руководство компании-заказчика

---

## 1. Назначение документа

В рамках развития системы TradeFrame предлагается реализовать функционал
«Корректировка остатков нефтепродуктов по результатам инвентаризации» для
автоматизированных АЗС без оператора (АКАЗС).

Документ описывает предлагаемую процедуру, правила её применения и форму
ввода данных. Просим внимательно ознакомиться, внести замечания и
утвердить — после утверждения мы начнём разработку.

## 2. Зачем это нужно

Периодически на АЗС выезжает комиссия для физической инвентаризации
остатков топлива в резервуарах. По результатам замеров комиссия может
зафиксировать расхождение между книжными (расчётными) остатками и
фактическими — в большую или меньшую сторону. Расхождение оформляется
актом и приказом генерального директора, после чего корректировка должна
быть внесена в учёт.

На обычных АЗС с оператором эта процедура уже работает: оператор перед
открытием новой смены вводит корректировку через интерфейс терминала на
станции. На **автоматизированных АЗС (АКАЗС) оператора нет**, и сейчас
внести корректировку в учёт некому. Из-за этого книжные остатки
расходятся с фактическими и не приводятся в соответствие до следующего
выезда специалиста с возможностью прямого доступа к терминалу.

## 3. Предлагаемое решение

Уполномоченный сотрудник заказчика заполняет в системе TradeFrame
**электронную форму корректировки** на основании приказа генерального
директора. Перед открытием очередной смены на АКАЗС система
**автоматически применит** корректировку — данные сменного отчёта будут
сформированы уже с учётом приказа.

## 4. Бизнес-процедура

### Шаг 1. Закрытие текущей смены и инвентаризация

Текущая смена на АЗС закрывается штатным образом. Комиссия выезжает на
станцию и проводит фактические замеры остатков в резервуарах.

### Шаг 2. Открытие следующей смены без корректировки

После закрытия предыдущей смены система автоматически открывает
следующую — но **без применения корректировок**. Эта смена работает
«как было» до получения утверждённого приказа.

### Шаг 3. Оформление приказа генеральным директором

Комиссия передаёт акт инвентаризации на утверждение. Генеральный
директор издаёт приказ с конкретными значениями корректировок по каждому
резервуару станции.

### Шаг 4. Ввод корректировки в TradeFrame

Уполномоченный сотрудник открывает в TradeFrame форму корректировки,
заполняет поля на основании приказа.

### Шаг 5. Автоматическое применение

Перед открытием ближайшей следующей смены, начало которой попадает на
указанное в форме время начала действия (или позже), система
автоматически применяет корректировку.

## 5. Форма документа корректировки (предлагаемый состав)

### 5.1 Шапка документа

сеть и торговая точка уже выбраны при открытии страницы оборудование 

| Поле | Обязательно | Кто заполняет | Комментарий |
| --- | --- | --- | --- |
| Номер приказа | Да | сотрудник | как указан в приказе |
| Дата приказа | Да | сотрудник | дата подписания приказа ген. директором |
| Дата фактической инвентаризации | Да | сотрудник | когда комиссия выезжала на АЗС |
| Время начала действия | Да | сотрудник | с какого момента корректировка должна применяться (см. §6) |
| Комментарий, причина расхождения | Нет | сотрудник | свободный текст |

### 5.2 Таблица корректировок по резервуарам

Автоматически подтягиваются все резервуары выбранной АЗС. По каждому
резервуару:

| Колонка | Кто заполняет | Комментарий |
| --- | --- | --- |
| Резервуар № | автоматически | номер резервуара на АЗС |
| Тип топлива | автоматически | АИ-92 / АИ-95 / АИ-98 / ДТ |
| Книжный остаток (литры) | автоматически | расчётное значение по системе на момент инвентаризации |
| Фактический остаток (литры) | сотрудник | значение из акта замера |
| Корректировка (литры) | автоматически | разница (фактический − книжный), с подсветкой знака |
| Книжная масса (кг) | автоматически | если применимо |
| Фактическая масса (кг) | сотрудник | если в приказе указано |
| Корректировка по массе (кг) | автоматически | если заполнены массы |

Сотрудник заполняет фактический остаток (и при необходимости массу) только по тем резервуарам, где приказом утверждена корректировка. По остальным
резервуарам корректировка не применяется (значения остаются книжными).

## 6. Правила применения

Просим утвердить следующие правила:

### 6.1 Время начала действия

- Время начала действия указывается сотрудником при заполнении формы.
- Это значение задаёт ориентир, начиная с которого корректировка ищет смену для применения. Конкретное правило выбора смены — см. §6.2.

### 6.2 Срок ввода и применение через смену

- Корректировка по умолчанию применяется **через смену** после введённого времени начала действия: пропускается ближайшая открывающаяся смена, корректировка попадает в следующую за ней. Это даёт гарантированный буфер на регистрацию данных в системе и контроль до открытия смены, в которой корректировка вступит в силу.
- Если по какой-либо причине применение не успело произойти — система переносит его на следующую смену **в пределах текущего отчётного месяца**.
- Если до конца отчётного месяца применить не удалось — документ автоматически помечается как просроченный и корректировка не применяется. Сотрудник должен переоформить документ на следующий отчётный период.

### 6.3 Однократное применение

- Каждая корректировка применяется **один раз** — к одной конкретной смене.
- После применения документ переходит в статус «Применён» и не может быть отменён.
- Если применённую корректировку нужно отменить или изменить — оформляется **новый** документ-сторно с противоположным знаком, на основании нового приказа.

### 6.4 Несколько корректировок на одну АЗС

- На одной АЗС может быть оформлено несколько утверждённых корректировок с разным временем начала действия. Система применит их в хронологическом порядке.
- Запрещено иметь два **активных** (ещё не применённых) документа с одинаковым временем начала действия — сотрудник должен выбрать один.

## 7. Кто имеет право работать с документом (RBAC)

Просим утвердить разграничение прав:

### 7.1 Создание и редактирование черновика

Сотрудник, имеющий право заполнять документы корректировки в своей сети АЗС.

> **Кого назначить:** \_\_\_\_\_\_\_\_ (на согласование)
>
> Варианты: бухгалтер сети, главный бухгалтер, специалист отдела учёта.

### 7.2 Утверждение документа в системе

Документ переходит из статуса «Черновик» в статус «Запланирован к применению» только после утверждения уполномоченным лицом. До утверждения документ корректировкой не считается и системой не применяется.

> **Кого назначить:** \_\_\_\_\_\_\_\_ (на согласование)
>
> Варианты: главный бухгалтер сети, директор сети, заместитель генерального директора по учёту.
