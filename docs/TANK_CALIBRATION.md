# Система автокалибровки резервуаров

## Обзор

Система автокалибровки резервуаров предназначена для точного учета топлива на АЗС путем автоматической корректировки показаний уровнемеров с учетом погрешностей оборудования, температурных факторов и других параметров.

## Возможности

- ✅ Настройка погрешностей оборудования (ТРК, уровнемеры)
- ✅ Учет температурных коэффициентов расширения топлива
- ✅ Учет естественной убыли и потерь при сливе
- ✅ Настройка временных интервалов анализа
- ✅ Пороговые значения для критических отклонений
- ✅ Геометрические параметры резервуара
- ✅ Фильтрация аномалий (периоды слива, ТО, статистические выбросы)
- ✅ Выбор метода калибровки (линейная регрессия, МНК, скользящее среднее)
- ⏳ Автоматический запуск калибровки по расписанию (в разработке)

## Архитектура

### Frontend

**Компоненты:**
- `src/components/tanks/TankCalibrationSettings.tsx` - UI для настройки параметров
- `src/components/tanks/TankAnalysisDialog.tsx` - модальное окно резервуара (таб "Калибровка")

**Типы:**
- `src/types/tanks.ts` - TypeScript типы для калибровки
  - `TankCalibrationSettings` - интерфейс настроек
  - `DEFAULT_CALIBRATION_SETTINGS` - значения по умолчанию

**Сервисы:**
- `src/services/tankCalibrationService.ts` - API клиент для работы с калибровкой

### Backend

**API Routes:**
- `server/routes/tankCalibration.js` - CRUD операции для настроек калибровки
  - `GET /api/tank-calibration/:tankId` - получить настройки
  - `POST /api/tank-calibration` - сохранить/обновить настройки
  - `DELETE /api/tank-calibration/:tankId` - удалить настройки
  - `POST /api/tank-calibration/:tankId/run` - запустить калибровку

### База данных

**Таблица:** `tank_calibration_settings`

**Миграция:** `database/migrations/create_tank_calibration_settings.sql`

**Структура:**
- Погрешности оборудования (dispensers_error_*, level_sensor_error_*)
- Температурные параметры (fuel_type, thermal_expansion_coefficient, и т.д.)
- Испарение и усадка (natural_loss_*, discharge_loss_percent)
- Временные параметры (averaging_period_minutes, analysis_window_days)
- Пороговые значения (min_change_for_calibration_liters, и т.д.)
- Геометрия резервуара (tank_shape, tank_tilt_degrees)
- Фильтрация аномалий (exclude_delivery_periods, outlier_filter_enabled)
- Метод калибровки (calibration_method, sensor_weight, dispenser_weight)

## Параметры калибровки

### 1. Погрешности оборудования

Согласно ГОСТ Р 8.579-2001:

- **Погрешность ТРК**: ±0.5% (типовое значение)
- **Погрешность уровнемера**: ±0.2-0.5%
- **Точность уровнемера**: ±1-3 мм

### 2. Температурные параметры

- **Коэффициент расширения**:
  - Бензин: 0.0012-0.0013 (1/°C)
  - Дизель: 0.0009-0.0010 (1/°C)
- **Базовая температура**: 15°C или 20°C
- **Рабочий диапазон**: обычно от -40°C до +50°C

### 3. Естественная убыль

- **Летний период**: до 0.8% от объема
- **Зимний период**: до 0.3% от объема
- **Потери при сливе**: 0.1-0.2%

### 4. Временные параметры

- **Период усреднения**: 15/30/60 минут
- **Окно анализа**: 7/14/30 дней
- **Время покоя резервуара**: 30 минут (для стабилизации после операций)

### 5. Пороговые значения

- **Минимальное изменение для калибровки**: 100 литров
- **Максимально допустимое расхождение**: 2% или 500 литров
- **Критическая ошибка**: 5% (требует ручной проверки)

### 6. Геометрия резервуара

- **Форма**: цилиндрический, эллиптический, прямоугольный
- **Наклон**: в градусах от горизонтали
- **Калибровочная таблица**: наличие таблицы уровень → объем

### 7. Фильтрация аномалий

- **Исключение периодов приема топлива**
- **Исключение периодов технического обслуживания**
- **Фильтр статистических выбросов** (3σ = 99.7% данных)

### 8. Метод калибровки

- **Линейная регрессия** - простой метод для резервуаров с линейной зависимостью
- **Метод наименьших квадратов (МНК)** - более точный для сложных зависимостей
- **Скользящее среднее** - сглаживание краткосрочных колебаний

**Весовые коэффициенты**:
- Вес данных уровнемера: 0.6 (60%)
- Вес данных ТРК: 0.4 (40%)

## Использование

### Настройка параметров калибровки

1. Откройте страницу **Резервуары** (`/point/tanks`)
2. Нажмите на карточку резервуара для открытия детального анализа
3. Перейдите на вкладку **"Калибровка"**
4. Настройте параметры в соответствующих разделах:
   - Оборудование
   - Температура
   - Потери
   - Время
   - Пороги
   - Расширенные
5. Нажмите **"Сохранить"**

### Запуск калибровки

**Ручной запуск:**
```bash
POST /api/tank-calibration/:tankId/run
```

**Автоматический запуск** (в разработке):
- Включите переключатель "Автоматическая калибровка"
- Калибровка будет запускаться по расписанию

### Просмотр результатов

Статус калибровки отображается в верхней части вкладки:
- 🔵 **Не калиброван** - калибровка еще не выполнялась
- 🟡 **В процессе** - калибровка выполняется
- 🟢 **Откалиброван** - последняя калибровка успешна
- 🔴 **Ошибка** - произошла ошибка при калибровке

## API эндпоинты

### Получить настройки калибровки

```http
GET /api/tank-calibration/:tankId
```

**Ответ:**
```json
{
  "id": "uuid",
  "tank_id": "1",
  "dispensers_error_percent": 0.5,
  "level_sensor_error_percent": 0.3,
  ...
}
```

### Сохранить настройки калибровки

```http
POST /api/tank-calibration
Content-Type: application/json

{
  "tank_id": "1",
  "dispensers_error_percent": 0.5,
  "level_sensor_error_percent": 0.3,
  ...
}
```

### Удалить настройки

```http
DELETE /api/tank-calibration/:tankId
```

### Запустить калибровку

```http
POST /api/tank-calibration/:tankId/run
```

**Ответ:**
```json
{
  "success": true,
  "message": "Calibration started",
  "tankId": "1"
}
```
