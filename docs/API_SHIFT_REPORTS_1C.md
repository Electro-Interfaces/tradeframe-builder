## Введение

Данный документ описывает интеграцию системы управления АЗС (STS API) с конфигурацией 1С для автоматической загрузки сменных отчетов.

### Основные возможности интеграции
- ✅ Загрузка списка смен за период
- ✅ Получение детального отчета по смене
- ✅ Автоматическая загрузка данных по ТРК, резервуарам, продажам
- ✅ Сверка данных с учетной системой 1С
- ✅ Контроль погрешностей и разностей

### Базовые параметры API
- **Base URL:** `https://pos.autooplata.ru/tms`
- **Протокол:** HTTPS (TLS 1.2+)
- **Аутентификация:** HTTP Basic Auth
- **Формат данных:** JSON
- **Кодировка:** UTF-8

## Методы API

### Метод 1: Получение списка смен

#### Endpoint
```
GET /v1/shifts?system={system}&station={station}&dt_beg={dt_beg}&dt_end={dt_end}
```

#### Код 1С

```bsl
// Функция: ПолучитьСписокСмен
// Параметры:
//   Система - Число (код системы, например 15)
//   ТорговаяТочка - Число (код ТТ, например 4)
//   ДатаНачала - Дата
//   ДатаОкончания - Дата
// Возврат: Массив структур со сменами
//
Функция ПолучитьСписокСмен(Знач Система, Знач ТорговаяТочка, Знач ДатаНачала, Знач ДатаОкончания) Экспорт

	Настройки = ПолучитьНастройкиПодключения(Система, ТорговаяТочка);
	Соединение = ПолучитьHTTPСоединение(Настройки);

	// Формируем строку запроса
	ПараметрыЗапроса = Новый Массив;
	ПараметрыЗапроса.Добавить("system=" + Формат(Система, "ЧГ="));
	ПараметрыЗапроса.Добавить("station=" + Формат(ТорговаяТочка, "ЧГ="));

	// Даты в формате ISO 8601
	Если ЗначениеЗаполнено(ДатаНачала) Тогда
		ДатаНачалаISO = XMLСтрока(ДатаНачала);
		ПараметрыЗапроса.Добавить("dt_beg=" + ДатаНачалаISO);
	КонецЕсли;

	Если ЗначениеЗаполнено(ДатаОкончания) Тогда
		ДатаОкончанияISO = XMLСтрока(ДатаОкончания);
		ПараметрыЗапроса.Добавить("dt_end=" + ДатаОкончанияISO);
	КонецЕсли;

	СтрокаПараметров = СтрСоединить(ПараметрыЗапроса, "&");
	АдресРесурса = "/v1/shifts?" + СтрокаПараметров;

	// Выполняем запрос
	Результат = ВыполнитьGETЗапрос(Соединение, АдресРесурса);

	// Результат - массив структур:
	// [
	//   {shift: 40, dt_open: "2025-10-04T00:00:55", dt_close: "2025-10-05T00:00:31"},
	//   {shift: 39, dt_open: "2025-10-03T00:01:12", dt_close: "2025-10-04T00:00:30"}
	// ]

	Возврат Результат;

КонецФункции
```

## Маппинг данных 1С ↔ API

### 1. Показания ТРК (psm.data)

| Поле API | Тип API | Поле 1С | Тип 1С | Преобразование |
|----------|---------|---------|--------|----------------|
| `pos` | number | `НомерPOS` | Число(2,0) | Прямое |
| `pump` | number | `НомерТРК` | Число(3,0) | Прямое |
| `nozzle` | string | `НомерПистолета` | Строка(10) | Прямое |
| `tank` | number | `Резервуар` | СправочникСсылка.Резервуары | Найти по номеру |
| `psm_beg` | number | `ПоказанияНачало` | Число(15,2) | Прямое |
| `psm_end` | number | `ПоказанияКонец` | Число(15,2) | Прямое |
| `service.service_code` | number | `ВидТоплива` | СправочникСсылка.ВидыТоплива | Найти по коду |
| `service.service_name` | string | - | - | Для проверки |
| `release.volume` | string | `ОтпущеноЛитров` | Число(15,3) | Число() |
| `release.cost` | string | `Сумма` | Число(15,2) | Число() |
| `density` | number | `Плотность` | Число(6,4) | Прямое |
| `price` | number | `ЦенаЗаЛитр` | Число(15,2) | Прямое |

#### Код преобразования

```bsl
// Процедура: ЗаполнитьПоказанияТРК
// Параметры:
//   ДокументОбъект - ДокументОбъект.СменныйОтчет
//   ДанныеPSM - Структура (из API)
//
Процедура ЗаполнитьПоказанияТРК(ДокументОбъект, Знач ДанныеPSM) Экспорт

	Если ДанныеPSM.Свойство("data") И ТипЗнч(ДанныеPSM.data) = Тип("Массив") Тогда

		ДокументОбъект.ПоказанияТРК.Очистить();

		Для Каждого Показания Из ДанныеPSM.data Цикл

			НоваяСтрока = ДокументОбъект.ПоказанияТРК.Добавить();
			НоваяСтрока.НомерPOS = Показания.pos;
			НоваяСтрока.НомерТРК = Показания.pump;
			НоваяСтрока.НомерПистолета = Показания.nozzle;

			// Находим резервуар по номеру
			НоваяСтрока.Резервуар = НайтиРезервуарПоНомеру(Показания.tank, ДокументОбъект.ТорговаяТочка);

			// Находим вид топлива по коду
			Если Показания.Свойство("service") И Показания.service.Свойство("service_code") Тогда
				НоваяСтрока.ВидТоплива = НайтиВидТопливаПоКоду(Показания.service.service_code);
			КонецЕсли;

			НоваяСтрока.ПоказанияНачало = Показания.psm_beg;
			НоваяСтрока.ПоказанияКонец = Показания.psm_end;
			НоваяСтрока.Плотность = Показания.density;
			НоваяСтрока.ЦенаЗаЛитр = Показания.price;

			// Данные отпуска
			Если Показания.Свойство("release") Тогда
				НоваяСтрока.ОтпущеноЛитров = Число(Показания.release.volume);
				НоваяСтрока.ОтпущеноКг = Число(Показания.release.amount);
				НоваяСтрока.Сумма = Число(Показания.release.cost);
			КонецЕсли;

		КонецЦикла;

	КонецЕсли;

КонецПроцедуры
```

### 2. Состояние резервуаров (release)

| Поле API | Тип API | Поле 1С | Тип 1С | Преобразование |
|----------|---------|---------|--------|----------------|
| `tank` | number | `Резервуар` | СправочникСсылка | Найти по номеру |
| `service.service_code` | number | `ВидТоплива` | СправочникСсылка | Найти по коду |
| `doc_beg.volume` | string | `ОстатокНачалоЛитров` | Число(15,3) | Число() |
| `doc_end.volume` | string | `ОстатокКонецЛитров` | Число(15,3) | Число() |
| `receipt.volume` | string | `ПоступилоЛитров` | Число(15,3) | Число() |
| `release.volume` | string | `ОтпущеноПоТРК` | Число(15,3) | Число() |
| `level_end` | number | `УровеньКонец` | Число(10,0) | мм |
| `temp_end` | number | `ТемператураКонец` | Число(5,1) | °C |
| `density_end` | number | `ПлотностьКонец` | Число(6,4) | г/см³ |
| `water.level` | number | `УровеньВоды` | Число(5,2) | см |
| `water.volume` | number | `ОбъемВоды` | Число(10,2) | л |

#### Код преобразования

```bsl
// Процедура: ЗаполнитьСостояниеРезервуаров
//
Процедура ЗаполнитьСостояниеРезервуаров(ДокументОбъект, Знач ДанныеRelease) Экспорт

	Если ТипЗнч(ДанныеRelease) = Тип("Массив") Тогда

		ДокументОбъект.СостояниеРезервуаров.Очистить();

		Для Каждого ДанныеРезервуара Из ДанныеRelease Цикл

			НоваяСтрока = ДокументОбъект.СостояниеРезервуаров.Добавить();

			// Резервуар и топливо
			НоваяСтрока.Резервуар = НайтиРезервуарПоНомеру(ДанныеРезервуара.tank, ДокументОбъект.ТорговаяТочка);
			Если ДанныеРезервуара.Свойство("service") Тогда
				НоваяСтрока.ВидТоплива = НайтиВидТопливаПоКоду(ДанныеРезервуара.service.service_code);
			КонецЕсли;

			// Остатки
			Если ДанныеРезервуара.Свойство("doc_beg") Тогда
				НоваяСтрока.ОстатокНачалоЛитров = Число(ДанныеРезервуара.doc_beg.volume);
				НоваяСтрока.ОстатокНачалоКг = Число(ДанныеРезервуара.doc_beg.amount);
			КонецЕсли;

			Если ДанныеРезервуара.Свойство("doc_end") Тогда
				НоваяСтрока.ОстатокКонецЛитров = Число(ДанныеРезервуара.doc_end.volume);
				НоваяСтрока.ОстатокКонецКг = Число(ДанныеРезервуара.doc_end.amount);
			КонецЕсли;

			// Поступление и отпуск
			Если ДанныеРезервуара.Свойство("receipt") Тогда
				НоваяСтрока.ПоступилоЛитров = Число(ДанныеРезервуара.receipt.volume);
			КонецЕсли;

			Если ДанныеРезервуара.Свойство("release") Тогда
				НоваяСтрока.ОтпущеноПоТРК = Число(ДанныеРезервуара.release.volume);
			КонецЕсли;

			// Замеры
			НоваяСтрока.УровеньКонец = ДанныеРезервуара.level_end;
			НоваяСтрока.ТемператураКонец = ДанныеРезервуара.temp_end;
			НоваяСтрока.ПлотностьКонец = ДанныеРезервуара.density_end;

			// Вода
			Если ДанныеРезервуара.Свойство("water") Тогда
				НоваяСтрока.УровеньВоды = ДанныеРезервуара.water.level;
				НоваяСтрока.ОбъемВоды = ДанныеРезервуара.water.volume;
			КонецЕсли;

			// РАСЧЕТНЫЕ ПОЛЯ
			НоваяСтрока.РасчетныйОстаток = НоваяСтрока.ОстатокНачалоЛитров
				+ НоваяСтрока.ПоступилоЛитров
				- НоваяСтрока.ОтпущеноПоТРК;

			НоваяСтрока.Разность = НоваяСтрока.ОстатокКонецЛитров - НоваяСтрока.РасчетныйОстаток;

			// Проверка превышения погрешности (10 литров)
			НоваяСтрока.ПревышениеПогрешности = (Abs(НоваяСтрока.Разность) > 10);

		КонецЦикла;

	КонецЕсли;

КонецПроцедуры
```

### 3. Продажи (sales)

| Поле API | Тип API | Поле 1С | Тип 1С | Преобразование |
|----------|---------|---------|--------|----------------|
| `pay_type.id` | number | `СпособОплаты` | СправочникСсылка | Маппинг ID → Справочник |
| `pay_type.name` | string | - | - | Для определения категории |
| `service.service_code` | number | `ВидТоплива` | СправочникСсылка | Найти по коду |
| `release.volume` | string | `КоличествоЛитров` | Число(15,3) | Число() |
| `release.cost` | string | `Сумма` | Число(15,2) | Число() |
| `release.discount` | number | `Скидка` | Число(15,2) | Прямое (только не купоны!) |

#### Маппинг способов оплаты

```bsl
// Функция: ПолучитьСпособОплатыПоIDиНазванию
// Возврат: СправочникСсылка.СпособыОплаты
//
Функция ПолучитьСпособОплатыПоIDиНазванию(Знач PayTypeID, Знач PayTypeName) Экспорт

	НазваниеНижний = НРег(PayTypeName);

	// Наличные
	Если НазваниеНижний = "наличные" Тогда
		Возврат Справочники.СпособыОплаты.Наличные;
	КонецЕсли;

	// Банковские карты
	Если Найти(НазваниеНижний, "сбербанк") > 0 ИЛИ Найти(НазваниеНижний, "карт") > 0 Тогда
		Возврат Справочники.СпособыОплаты.БанковскиеКарты;
	КонецЕсли;

	// Безналичные (МобилПр и т.п.)
	Если Найти(НазваниеНижний, "мобил") > 0 Тогда
		Возврат Справочники.СпособыОплаты.Безналичные;
	КонецЕсли;

	// Купон - корректировка (отдельный элемент)
	Если Найти(НазваниеНижний, "купон") > 0 Тогда
		Возврат Справочники.СпособыОплаты.КорректировкаКупон;
	КонецЕсли;

	// Если не определили - возвращаем "Прочее"
	Возврат Справочники.СпособыОплаты.Прочее;

КонецФункции
```

#### Код преобразования продаж

```bsl
// Процедура: ЗаполнитьПродажи
//
Процедура ЗаполнитьПродажи(ДокументОбъект, Знач ДанныеSales) Экспорт

	Если ТипЗнч(ДанныеSales) = Тип("Массив") Тогда

		ДокументОбъект.Продажи.Очистить();

		Для Каждого ДанныеПродажи Из ДанныеSales Цикл

			// Флаг - это купон или нет
			ЭтоКупон = (Найти(НРег(PayTypeName), "купон") > 0);

			// Обрабатываем каждое топливо
			Если ДанныеПродажи.Свойство("fuel") И ТипЗнч(ДанныеПродажи.fuel) = Тип("Массив") Тогда

				Для Каждого ДанныеТоплива Из ДанныеПродажи.fuel Цикл

					НоваяСтрока = ДокументОбъект.Продажи.Добавить();

					// Вид топлива

						НоваяСтрока.ВидТоплива = НайтиВидТопливаПоКоду(ДанныеТоплива.service.service_code);
					КонецЕсли;

					НоваяСтрока.СпособОплаты = СпособОплаты;

					// Данные продажи
					Если ДанныеТоплива.Свойство("release") Тогда
						НоваяСтрока.КоличествоЛитров = Число(ДанныеТоплива.release.volume);

						// ВАЖНО: Скидка из купонов НЕ учитывается!
						Если НЕ ЭтоКупон Тогда
							НоваяСтрока.Скидка = ДанныеТоплива.release.discount;
						КонецЕсли;
					КонецЕсли;

				КонецЦикла;

			КонецЕсли;

		КонецЦикла;

	КонецЕсли;

КонецПроцедуры
```

### Алгоритм 1: Расчет расшифровки реализации

**Задача:** Сформировать таблицу с колонками: Прокачка | По картам | Скидка | За наличные | Безнал. | Всего | Разница

```bsl

//   ДанныеSales - Массив (из API)

	Расшифровка.Колонки.Добавить("ПоКартамЛитров", Новый ОписаниеТипов("Число", Новый КвалификаторыЧисла(15, 3)));
	Расшифровка.Колонки.Добавить("ПоКартамРублей", Новый ОписаниеТипов("Число", Новый КвалификаторыЧисла(15, 2)));

	Расшифровка.Колонки.Добавить("НаличныеЛитров", Новый ОписаниеТипов("Число", Новый КвалификаторыЧисла(15, 3)));
	Расшифровка.Колонки.Добавить("НаличныеРублей", Новый ОписаниеТипов("Число", Новый КвалификаторыЧисла(15, 2)));
	Расшифровка.Колонки.Добавить("БезналЛитров", Новый ОписаниеТипов("Число", Новый КвалификаторыЧисла(15, 3)));

	Расшифровка.Колонки.Добавить("РазницаЛитров", Новый ОписаниеТипов("Число", Новый КвалификаторыЧисла(15, 3)));

	Для Каждого ДанныеПродажи Из ДанныеSales Цикл

		PayTypeName = НРег(ДанныеПродажи.pay_type.name);

		Для Каждого ДанныеТоплива Из ДанныеПродажи.fuel Цикл

			КодТоплива = ДанныеТоплива.service.service_code;
			НаименованиеТоплива = ДанныеТоплива.service.service_name;

			// Ищем строку для данного топлива

				Строка.СкидкаРублей = Строка.СкидкаРублей + Скидка;
				Строка.ВсегоЛитров = Строка.ВсегоЛитров + Объем;
			КонецЕсли;

		КонецЦикла;

	КонецЦикла;

	// Рассчитываем прокачку и разницу (после всех данных)
	Для Каждого Строка Из Расшифровка Цикл
		// Прокачка берется из release[].release.volume для данного топлива
		// Разница = Прокачка - Всего
		// (Это нужно сделать отдельно, используя данные release)
	КонецЦикла;

	Возврат Расшифровка;

КонецФункции
```

### Алгоритм 2: Расчет движения наличных

**Формула:**
- Принято по смене = `operation.id: 7` (closing)
- Внесено за смену = сумма `operation.id: 3` (income)
- Выручка за смену = из продаж (наличные)
- Передано по смене = Принято + Внесено + Выручка

```bsl
// Функция: РассчитатьДвижениеНаличных
// Параметры:
//   ДанныеMoney - Массив (из API)
//   ДанныеSales - Массив (для расчета выручки наличными)
// Возврат: Структура с итогами
//
Функция РассчитатьДвижениеНаличных(Знач ДанныеMoney, Знач ДанныеSales) Экспорт

	Результат = Новый Структура;
	Результат.Вставить("ПринятоПоСмене", 0);
	Результат.Вставить("ВнесеноЗаСмену", 0);
	Результат.Вставить("ВыручкаЗаСмену", 0);
	Результат.Вставить("ПередаНоПоСмене", 0);

	// 1. Принято по смене (operation.id: 7)
	Для Каждого ДанныеОперации Из ДанныеMoney Цикл
		Если ДанныеОперации.operation.id = 7 Тогда
			Результат.ПринятоПоСмене = ДанныеОперации.money;
			Прервать;
		КонецЕсли;
	КонецЦикла;

	// 2. Внесено за смену (operation.id: 3)
	Для Каждого ДанныеОперации Из ДанныеMoney Цикл
		Если ДанныеОперации.operation.id = 3 Тогда
			Результат.ВнесеноЗаСмену = Результат.ВнесеноЗаСмену + ДанныеОперации.money;
		КонецЕсли;
	КонецЦикла;

	// 3. Выручка за смену - из продаж (наличные)
	Для Каждого ДанныеПродажи Из ДанныеSales Цикл
		PayTypeName = НРег(ДанныеПродажи.pay_type.name);

		Если Найти(PayTypeName, "наличн") > 0 Тогда
			Для Каждого ДанныеТоплива Из ДанныеПродажи.fuel Цикл
				Сумма = Число(ДанныеТоплива.release.cost);
				Результат.ВыручкаЗаСмену = Результат.ВыручкаЗаСмену + Сумма;
			КонецЦикла;
		КонецЕсли;
	КонецЦикла;

	// 4. Передано по смене
	Результат.ПередаНоПоСмене = Результат.ПринятоПоСмене + Результат.ВнесеноЗаСмену + Результат.ВыручкаЗаСмену;

	Возврат Результат;

КонецФункции
```

```bsl
		// 4. Заполняем табличные части
		ЗаполнитьПоказанияТРК(ДокументОбъект, ДанныеAPI.psm);

		ЗаполнитьДвижениеНаличных(ДокументОбъект, ДанныеAPI.money, ДанныеAPI.sales);

		// 5. Записываем и проводим
		ДокументОбъект.Записать(РежимЗаписиДокумента.Проведение);

		Сообщить(СтрШаблон("Сменный отчет №%1 успешно загружен и проведен!", НомерСмены));

	Исключение

		ТекстОшибки = ОписаниеОшибки();
		Сообщить(СтрШаблон("Ошибка загрузки сменного отчета: %1", ТекстОшибки), СтатусСообщения.Важное);

	КонецПопытки;

КонецПроцедуры
```

## Обработка ошибок

### Типичные ошибки и их обработка

#### 1. Ошибка 401 - Unauthorized

```bsl
Если Ответ.КодСостояния = 401 Тогда
	// Неверные credentials
	ВызватьИсключение "Ошибка авторизации! Проверьте логин и пароль в настройках подключения.";
КонецЕсли;
```

#### 2. Ошибка 404 - Not Found

```bsl
Если Ответ.КодСостояния = 404 Тогда
	// Смена или станция не найдена
	ВызватьИсключение СтрШаблон("Смена №%1 не найдена в системе!", НомерСмены);
КонецЕсли;
```

#### 3. Ошибка сети

```bsl
Попытка
	Ответ = Соединение.Получить(Запрос);
Исключение
	ТекстОшибки = ОписаниеОшибки();

	Если Найти(ТекстОшибки, "timeout") > 0 Тогда
		ВызватьИсключение "Превышено время ожидания ответа от сервера!";
	ИначеЕсли Найти(ТекстОшибки, "connection") > 0 Тогда
		ВызватьИсключение "Ошибка соединения с сервером! Проверьте доступность хоста.";
	Иначе
		ВызватьИсключение ТекстОшибки;
	КонецЕсли;
КонецПопытки;
```

## Контрольные точки валидации

### 1. Проверка погрешности ТРК

```bsl
// Функция: ПроверитьПогрешностьТРК
// Возврат: Булево (Истина если погрешность превышена)
//
Функция ПроверитьПогрешностьТРК(Знач ПрокачкаПоТРК, Знач ПродажиПоКассе) Экспорт

	Разность = Abs(ПрокачкаПоТРК - ПродажиПоКассе);
	ДопустимаяПогрешностьЛитров = 10; // Фиксированное значение

	Возврат (Разность > ДопустимаяПогрешностьЛитров);

КонецФункции
```

### 2. Проверка погрешности резервуаров

```bsl
// Функция: ПроверитьПогрешностьРезервуара
//
Функция ПроверитьПогрешностьРезервуара(Знач РасчетныйОстаток, Знач ФактическийОстаток) Экспорт

	Разность = Abs(РасчетныйОстаток - ФактическийОстаток);
	ДопустимаяРазность = 10; // Литров

	Возврат (Разность > ДопустимаяРазность);

КонецФункции
```

### 3. Контроль денежных средств

```bsl
// Функция: ПроверитьБалансНаличных
//
Функция ПроверитьБалансНаличных(Знач Принято, Знач Внесено, Знач Выручка, Знач Передано) Экспорт

	РасчетноеПередано = Принято + Внесено + Выручка;
	Разность = Abs(РасчетноеПередано - Передано);
	ДопустимаяПогрешность = 0.01; // 1 копейка

	Возврат (Разность > ДопустимаяПогрешность);

КонецФункции
```
