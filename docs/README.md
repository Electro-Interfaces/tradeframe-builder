## Исторические материалы

`_archive/`, `mobile/`, `operations/` и часть `setup/` содержат полезные отчеты и планы, но не являются текущим runbook. Перед использованием проверять по `DOCS_STATUS.md`, `DOCUMENTATION_AUDIT.md` и коду.

## Пользовательские материалы

`user-guide/` содержит руководства, скриншоты, html/docx/pdf материалы. Перед внешней публикацией нужна отдельная сверка с текущим UI.
