# Archive

Эта папка содержит исторические материалы. Их нельзя использовать как текущую инструкцию без сверки с кодом и актуальными документами:

- `../HANDOVER.md`
- `../ARCHITECTURE_CURRENT.md`
- `../ENVIRONMENT.md`
- `../OPERATIONS_RUNBOOK.md`
- `../DOCS_STATUS.md`

## Разделы

| Папка | Содержание |
| --- | --- |
| `deployment-legacy/` | старые схемы деплоя, GitHub Pages, прежние планы test/prod |
| `migration/` | материалы миграции Supabase -> PostgreSQL и связанные handoff-планы |
| `reports/` | исследовательские отчеты |

Архивные документы сохраняются для истории решений и диагностики, но не являются источником правды для версии 2.1.3.
