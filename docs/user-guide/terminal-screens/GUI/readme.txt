Основной экран - paytype.png
Экран окончания оформления заказа - finish.png

Навигация осуществляется с помощью выбора пункта меню, кнопок "Далее" и "Назад". На любом этапе оформления заказа можно вернуться назад и изменить выбор. Исключение: после внесения наличных нельзя вернуться назад.

Заказ автоматически отменяется, спустя определенное время (настроено 5 мин.)
После окончания оформления заказа (finish.png) экран автоматически подтверждается, спустя определенное время (настрено 30 сек.)

Смена:
Открытие/закрытие смены
Печать сменых/промежуточных отчетов
Инкассация

Касса:
Х-отчет
Z-отчет - печать бумажного отчета
Z-отчет (эл-ый) - печать отчета в буфер
Z-отчет (печать) - печать отчетов из буфера
Открыть смену на кассе

Приемка:
Начать налив - фиксация топлива в резервуаре на текущий момент
Закончить налив - фиксация топлива в резервуаре на текущий момент и занесение в таблицу информации о остатках: начальный, конечный
Ввод ТТН - ввод ТТН. По окончании ввода предложит начать налив. Можно вводить и после налива.

Варианты действий: 
Ввод ТТН (согласиться начать налив) -> Закончить налив
Начать налив -> Закончить налив -> Ввод ТТН (отказаться от начала налива)
Начать налив -> Ввод ТТН (отказаться от начала налива) -> Закончить налив

Осуществлять налив можно одновременно только на одном резервуаре. Т.е. нельзя начинать налив оджновременно по нескольким резервуарам, не закончив по предыдущему.
Вводить ТТН можно по нескольким резервуарам.
