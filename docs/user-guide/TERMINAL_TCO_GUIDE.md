## 1. Что такое ТСО?

**ТСО (Терминал самообслуживания)** — программно-аппаратный комплекс, который позволяет клиентам самостоятельно оплачивать топливо без помощи оператора. ТСО подключается к облачной платформе **TradeFrame** и может работать как дополнительный модуль к АЗС с оператором или как ядро автоматической АЗС (ААЗС).

### Преимущества для бизнеса

| Преимущество | Описание |
|--------------|----------|
| **Снижение очередей** | Клиенты не ждут оператора |
| **Работа 24/7** | Терминал работает круглосуточно без персонала |
| **Экономия на персонале** | Меньше операторов или полностью без них |
| **Контроль в реальном времени** | Все операции видны в облачной платформе TradeFrame |
| **Удалённое управление** | Контроль резервуаров и оборудования через TradeFrame |

### Способы оплаты на ТСО

- **Наличные** — оплата купюрами через купюроприёмник
- **Банковская карта** — Visa, MasterCard, МИР и другие
- **Топливная карта** — корпоративные и дисконтные карты
- **Онлайн-заказ** — оплата через мобильное приложение (заказ создаётся заранее, клиент только подтверждает на терминале)

### Оборудование ТСО

```
┌─────────────────────────────────────┐
│               ТСО                   │
├─────────────────────────────────────┤
│  Сенсорный экран                    │ ← Клиент нажимает на экран
│  Купюроприёмник                     │ ← Принимает наличные
│  Картридер                          │ ← Читает топливные карты
│  Банковский терминал                │ ← Принимает банковские карты
│  Принтер чеков                      │ ← Печатает чеки
└─────────────────────────────────────┘
```

## 2. Экосистема TradeSuite

**TradeSuite** — зонтичный бренд, объединяющий комплекс решений для топливного бизнеса.

### 2.1 Приложения экосистемы (Trade*)

| Приложение | Назначение |
|------------|------------|
| **TradeFrame** | Облачная платформа управления станциями |
| **TradeCorp** | Корпоративные топливные карты (B2B) |
| **TradeBonus** | Программа лояльности (B2C) |
| **TradeGate** | Интеграция с агрегаторами и онлайн-заказы |

### 2.2 Торговые точки TradeFrame

К платформе **TradeFrame** подключаются торговые точки разных типов:

| Код | Тип точки | Назначение |
|-----|-----------|------------|
| **АЗС** | **АЗС с оператором** | Классическая станция с персоналом |
| **ААЗС** | **Автоматическая АЗС** | Без персонала (включая контейнерные) |
| **АГЗС** | **АГЗС** | Газовая станция (пропан-бутан) |
| **ТСО** | **Терминал самообслуживания** | Модуль к АЗС или ядро ААЗС |

### 3.1 ААЗС — Автоматическая АЗС

**Полностью автоматическая станция без оператора**

![ААЗС — Автоматическая АЗС](terminal-screens/Gemini_Generated_Image_bosuk0bosuk0bosu.png)
*Схема работы автоматической АЗС: ТСО управляет всей станцией*

**Особенности ААЗС:**

| Функция | Описание |
|---------|----------|
| **Полная автономность** | Станция работает без персонала 24/7 |
| **Контроль резервуаров** | Интеграция с уровнемерами для мониторинга остатков |
| **Удалённое управление** | Все данные передаются в TradeFrame |
| **Автоматические уведомления** | Оповещения о низком уровне топлива, неисправностях |
| **Экономичность** | Минимальные затраты на эксплуатацию |

**Идеально подходит для:**
- Удалённых локаций (карьеры, стройплощадки, склады)
- Корпоративных заправок для автопарка
- Небольших населённых пунктов
- Придорожных станций с низким трафиком

---

### 3.2 АЗС + ТСО — Терминал на АЗС с оператором

**ТСО как дополнительный модуль к АЗС с оператором**

![АЗС + ТСО — гибридный режим](terminal-screens/Gemini_Generated_Image_ma7oq3ma7oq3ma7o.png)
*Днём — два потока клиентов, ночью — станция работает без персонала*

**Режимы работы:**

| Время | Режим работы | Описание |
|-------|--------------|----------|
| **День** | Параллельно с оператором | Ускорение обслуживания, 2 точки продаж |
| **Ночь** | Самостоятельно | Станция работает без персонала |
| **Праздники** | Самостоятельно | Не нужно выводить оператора |

**Преимущества АЗС + ТСО:**

| Преимущество | Описание |
|--------------|----------|
| **Ускорение обслуживания** | Два потока клиентов одновременно |
| **Круглосуточная работа** | Ночью станция работает без оператора |
| **Экономия на персонале** | Меньше ночных смен для операторов |
| **Гибкость** | Переключение режимов по расписанию |

### 3.3 Удалённое управление через TradeFrame

TradeFrame предоставляет широкие возможности для удаленного администрирования:

| Функция | Описание |
|---------|----------|
| **Управление питанием** | Удаленная перезагрузка станции и терминала |
| **Ценообразование** | Централизованная установка и изменение цен на топливо |
| **Оповещения** | Гибкая настройка параметров уведомлений (Telegram, Email, SMS) |
| **Мониторинг состояния** | Контроль работоспособности терминала и всех узлов (принтер, купюроприемник и др.) |
| **Автокалибровка** | Автоматическая калибровка резервуаров на основе данных проливов |
| **Анализ запасов** | Сверка книжных остатков с фактическими замерами уровнемеров |
| **Отчетность** | Формирование и отправка сменных отчетов |

## 4. Инструкция по использованию терминала оплаты на АЗС

Терминал ТСО позволяет быстро и удобно оплатить топливо. Следуйте простым шагам ниже.

### Навигация по меню

- Навигация осуществляется с помощью выбора пункта меню и кнопок **«Далее»** и **«Назад»**
- На любом этапе оформления заказа можно вернуться назад и изменить выбор
- **Исключение:** после внесения наличных вернуться назад нельзя
- **Автоматическая отмена:** заказ автоматически отменяется через 5 минут бездействия
- **Автоподтверждение:** после завершения заказа экран автоматически подтверждается через 30 секунд

---

### Способ 1: Оплата наличными

**Быстрый способ:** Достаточно вставить купюру прямо на главном экране — терминал автоматически перейдёт к оформлению.

**Стандартный способ:**

1. На главном экране выберите **«Наличные и купоны»** → **«Наличные»**

2. **Внесите купюры**

   ![Внесение наличных](terminal-screens/GUI/cash.png)

   После внесения всех купюр нажмите кнопку **«Далее»**

3. **Снимите пистолет с нужной ТРК**

   ![Выбор ТРК](terminal-screens/GUI/pump.png)

   Колонка выбирается автоматически при снятии пистолета. Убедитесь, что на экране отображается нужное топливо и цена.

   ![Снимите пистолет](terminal-screens/GUI/nozzle.png)

   > Если пистолет ещё не снят, терминал напомнит снять его с выбранной колонки

4. **Проверьте итоговую информацию**

   ![Итого](terminal-screens/GUI/total.png)

   Убедитесь, что всё выбрано правильно, и нажмите **«Далее»**

5. **Дождитесь печати чека**

   ![Печать чека](terminal-screens/GUI/cheque.png)

6. **Заберите чек и заправляйтесь!**

   ![Завершение](terminal-screens/GUI/finish.png)

> **ВАЖНО! Сохраняйте чек!**
> Если вы заправили не весь оплаченный объём, на чеке будет напечатан **номер купона** на остаток. Используйте его для следующей заправки.

---

### Способ 2: Использование купона

Купон выдаётся, если при оплате наличными вы заправили меньше оплаченного объёма.

1. На главном экране выберите **«Наличные и купоны»** → **«Купон»**

2. **Введите номер купона**

   ![Ввод купона](terminal-screens/GUI/coupon.png)

   Введите номер купона, указанный на вашем чеке

3. **Снимите пистолет с нужной ТРК** — колонка выберется автоматически. Убедитесь, что топливо соответствует купону.

4. **Подтвердите заказ** и заберите чек

> **Примечание:**
> - Если выбран другой тип топлива, терминал предложит снять правильный пистолет
> - Если по купону топливо не было получено ранее, к отпуску разрешено любое топливо

---

### Способ 3: Оплата банковской картой

1. На главном экране выберите **«Карта банка»**

2. **Выберите основание**

   ![Выбор основания](terminal-screens/GUI/ips_base.png)

   - **На сумму** — заправка на определённую сумму
   - **На литры** — заправка определённого количества литров

3. **Введите сумму или литры**

   ![Ввод литров](terminal-screens/GUI/ips_litre.png)

   ![Ввод суммы](terminal-screens/GUI/ips_money.png)

4. **Снимите пистолет с нужной ТРК** — колонка выберется автоматически. Проверьте информацию о топливе.

5. **Проверьте итоговую информацию** на экране подтверждения

6. **Приложите карту к терминалу банка**

   ![Ожидание карты](terminal-screens/GUI/ips_wait.png)

   Дождитесь окончания обработки платежа

7. **Заберите чек и заправляйтесь!**

> **ВАЖНО!** Если в бак поместится меньше топлива, чем оплачено, разница будет автоматически возвращена на карту.

---

### Способ 4: Оплата топливной корпоративной картой

Топливные карты выдаются организациям для безналичной заправки служебного транспорта. Карта привязана к корпоративному счёту компании.

1. На главном экране выберите **«Топливная карта»**

2. **Приложите карту к считывателю** терминала

3. **Выберите операцию**

   ![Меню топливной карты](terminal-screens/GUI/fuel_card_menu.jpg)

   - **Отпуск** — заправка топлива (основная операция)
   - **Возврат** — возврат средств на карту (если заправили меньше)
   - **Доп. операции** — дополнительные сервисы
   - **След. кошелёк** — переключение между кошельками на карте (если их несколько)

4. **Снимите пистолет с нужной ТРК**

   ![Снимите пистолет](terminal-screens/GUI/fuel_card_nozzle.jpg)

   Колонка выбирается автоматически при снятии пистолета.

5. **Проверьте итоговую информацию**

   ![Итого](terminal-screens/GUI/fuel_card_total.jpg)

   Убедитесь, что отображается нужное топливо и объём, нажмите **«Далее»**

6. **Заберите чек и заправляйтесь!**

> **Особенности топливных карт:**
> - Лимиты на заправку устанавливаются работодателем
> - Доступные виды топлива могут быть ограничены
> - Все операции фиксируются и доступны в отчётах компании
> - При недостатке средств на счёте терминал сообщит об этом

| **Ввод ТТН** | Ввод товарно-транспортной накладной |

**Варианты последовательности действий:**

1. `Ввод ТТН` → согласиться начать налив → `Закончить налив`
2. `Начать налив` → `Закончить налив` → `Ввод ТТН` (отказаться от начала)
3. `Начать налив` → `Ввод ТТН` (отказаться) → `Закончить налив`

> **Важно:**
> - Налив можно осуществлять только на **одном резервуаре** одновременно
> - Нельзя начать налив на другом резервуаре, не закончив предыдущий
> - ТТН можно вводить по нескольким резервуарам параллельно
