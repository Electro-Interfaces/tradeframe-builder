## I. ВВЕДЕНИЕ В ЭКОСИСТЕМУ

### О платформе TradeControl

**TradeControl** — это комплексная экосистема цифровизации бизнес-процессов для торговых сетей АЗС. Платформа объединяет управление операциями, аналитику, мониторинг оборудования и коммуникации в единое облачное решение.

#### 🎯 Миссия платформы

Предоставить владельцам и менеджерам торговых сетей АЗС современный инструмент для:
- **Оперативного контроля** — мгновенный доступ к данным о продажах, остатках, оборудовании
- **Принятия решений** — аналитика и прогнозы на основе реальных данных
- **Автоматизации** — снижение ручного труда через автоматические уведомления и отчеты
- **Масштабирования** — управление от одной точки до сети из десятков АЗС

#### 🌟 Ключевые преимущества

| Преимущество | Описание |
|--------------|----------|
| **🚀 Быстрый доступ** | Работает на любом устройстве — смартфон, планшет, компьютер |
| **📱 Мобильное приложение** | PWA технология — устанавливается одним кликом, работает офлайн |
| **🔔 Умные уведомления** | Telegram + Email — никогда не пропустите важные события |
| **📊 Визуальная аналитика** | Графики, дашборды, отчеты — данные в понятном виде |
| **🔐 Безопасность** | Многоуровневая система защиты данных и доступа |
| **🔄 Интеграции** | Подключение к POS-системам, 1C, внешним API |

---

### Что такое TradeControl Builder

**TradeControl Builder** — это фронтенд-интерфейс экосистемы TradeControl, который вы используете для работы с системой. Это Progressive Web Application (PWA), которое сочетает лучшее из веб- и мобильных приложений.

#### Что умеет TradeControl Builder?

**1. Управление торговыми сетями:**
- 🏢 Мониторинг всех торговых точек в едином интерфейсе
- 📈 Агрегированная аналитика по всей сети
- 💰 Централизованное управление ценами
- 📊 Сравнительные отчеты по точкам

**2. Контроль торговых точек:**
- ⛽ Мониторинг резервуаров в режиме реального времени
- 🖥️ Статус POS-терминалов и оборудования
- 💵 Купюроприемники и кассовые операции
- 📍 Координаты и информация о точках

**3. Система коммуникаций:**
- 🔔 Автоматические уведомления о критических событиях
- 📨 Рассылка новостей и объявлений
- 📱 Telegram бот для мгновенных уведомлений
- 📧 Email рассылки с шаблонами

**4. Аналитика и отчеты:**
- 📊 Графики продаж по видам топлива
- 📉 Тренды и прогнозы
- 🧾 Сменные отчеты
- 📈 Финансовые показатели

**5. Администрирование:**
- 👥 Управление пользователями и ролями
- 🔒 Гранулярные права доступа
- 📋 Журнал аудита действий
- ⚙️ Настройки интеграций

#### Компоненты экосистемы

**1. Frontend (TradeControl Builder):**
- Single Page Application на React
- Адаптивный дизайн для всех устройств
- Офлайн-режим с Service Worker
- Оптимистичные обновления UI

**2. Backend Proxy:**
- Централизованная точка доступа к данным
- Управление JWT токенами
- Агрегация запросов к различным API
- Автоматические проверки и уведомления

**3. База данных (Supabase):**
- Пользователи, роли, права
- Торговые сети и точки
- Оборудование и шаблоны
- История уведомлений

**4. Внешние системы:**
- **STS API** — данные POS-систем
- **Telegram** — мгновенные уведомления
- **Email** — формальные уведомления

## II. ВОЗМОЖНОСТИ ПЛАТФОРМЫ

### Обзор функциональности

TradeControl Builder предоставляет полный набор инструментов для управления торговой сетью АЗС. Функциональность организована в несколько модулей:

#### 📊 Модуль "Торговые сети"

**Назначение:** Управление и мониторинг всей торговой сети на агрегированном уровне.

**Возможности:**
- 🏢 **Обзор сети** — ключевые метрики и показатели
  - Общая выручка по всем точкам
  - Количество транзакций
  - Средний чек
  - Топ-3 точки по продажам

- 💰 **Операции и транзакции** — детальная информация о продажах
  - Фильтрация по дате, точке, типу топлива
  - Экспорт в Excel/CSV
  - Поиск конкретных транзакций
  - Графики продаж

- 📦 **Поступления товаров** — учет поступлений топлива
  - История поставок
  - Остатки после поступления
  - Сверка с накладными

- 📋 **Сменные отчеты** — отчеты по сменам операторов
  - ПСМ (показания счетчиков)
  - Продажи по видам топлива
  - Наличные/безнал
  - Расхождения

- 🎫 **Купоны** — управление скидочными программами
  - Создание купонов
  - Отслеживание использования
  - Статистика эффективности

---

#### ⛽ Модуль "Торговая точка"

**Назначение:** Управление отдельной торговой точкой (АЗС).

**Возможности:**
- 💵 **Управление ценами** — установка цен на топливо
  - Текущие цены по видам топлива
  - Планирование изменений цен
  - История изменений
  - Синхронизация с POS

- 🛢️ **Резервуары** — мониторинг топливных резервуаров
  - Уровень заполнения (%, литры)
  - Температура
  - Плотность
  - Объем доступного топлива
  - Графики изменения уровня

- 🖥️ **Оборудование** — статус и контроль оборудования
  - POS-терминалы (онлайн/офлайн)
  - Купюроприемники (заполнение)
  - ТРК (топливо-раздаточные колонки)
  - Датчики резервуаров
  - История неисправностей

---

#### 🔔 Модуль "Уведомления"

**Назначение:** Автоматические и ручные уведомления о событиях.

**Возможности:**
- ⚙️ **Настройка уведомлений** — персональные настройки
  - Выбор каналов доставки (Telegram, Email)
  - Подписки на типы событий
  - Режим "Не беспокоить"
  - Фильтры по приоритетам

- 📱 **Telegram интеграция** — мгновенные уведомления
  - Привязка Telegram аккаунта
  - Управление через бот @TradeControlDW_Bot
  - Команды бота (/start, /help, /status)

- 📧 **Email уведомления** — формальные уведомления
  - Настройка email адреса
  - Шаблоны писем
  - HTML форматирование

**Типы автоматических уведомлений:**
- 🔴 **Критические:**
  - Оборудование недоступно (offline)
  - Критически низкий уровень топлива
  - Смена не закрыта в срок

- 🟠 **Важные:**
  - Превышение порога купюроприемника
