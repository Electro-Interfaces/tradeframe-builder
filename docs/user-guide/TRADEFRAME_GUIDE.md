## 1. Что такое TradeFrame Builder?

**TradeFrame Builder** — это облачная платформа для централизованного управления сетью АЗС. Система объединяет все форматы топливного бизнеса в единое цифровое пространство: классические станции с операторами, автоматические терминалы самообслуживания и гибридные форматы.

![Главный экран TradeFrame Builder](tradeframe-screens/01_overview.png)
*Главный экран — обзор сети с ключевыми показателями*

### Что можно делать в TradeFrame

**Смотреть общую картину по сети**
- Сколько продали топлива сегодня / за неделю / за месяц
- Выручка по каждой станции
- Какое топливо продаётся лучше всего
- Сравнение станций между собой

**Анализировать продажи по способам оплаты**
- Наличные, банковские карты, онлайн-заказы
- Корпоративные карты, купоны
- Количество операций и сумма по каждому способу

**Следить за резервуарами**
- Уровень топлива в каждом резервуаре
- Температура и плотность
- Когда нужно заказывать поставку
- История поступлений (ТТН)

**Управлять ценами**
- Текущие цены на всех станциях в одной таблице
- Изменение цен на одной станции или сразу на всех
- Планирование изменения цен по расписанию

**Работать со сменными отчётами**
- Журнал всех смен
- Детали по каждой смене: продажи, поступления, остатки
- Показания счётчиков (ПСМ)
- Данные по резервуарам на начало и конец смены

**Контролировать оборудование**
- Статус всех ТРК (топливораздаточных колонок)
- Терминалы самообслуживания
- Купюроприёмники — уровень заполнения
- Когда нужна инкассация

**Получать уведомления**
- Telegram-бот присылает важные события
- Email-уведомления
- Настройка: что присылать и когда
- Режим «не беспокоить» на ночь

### Ключевые возможности

| Возможность | Описание |
|-------------|----------|
| **Единый интерфейс** | Управление всеми форматами АЗС из одного окна |
| **Данные в реальном времени** | Транзакции, остатки топлива, статусы оборудования |
| **Интеллектуальный учёт** | Автокалибровка резервуаров с учётом температуры и плотности |
| **Проактивные уведомления** | Telegram и Email оповещения о критических событиях |
| **Мобильный доступ** | PWA-приложение для работы с любого устройства |

### Для кого предназначена система

| Роль | Возможности |
|------|-------------|
| **Владелец/Директор** | Общая картина рентабельности, сравнение эффективности точек |
| **Менеджер сети** | Ценовая политика, логистика поставок, анализ продаж |
| **Менеджер АЗС** | Контроль оборудования, планирование ТО и инкассации |
| **Оператор** | Данные своей станции, уведомления о проблемах |
| **Бухгалтер** | Сменные отчёты, сверка остатков, интеграция с 1С |

## 2. Экосистема TradeSuite

**TradeSuite** — зонтичный бренд, объединяющий комплекс программных решений для автоматизации топливного бизнеса. Продукты экосистемы работают как единое целое, обеспечивая полный цикл управления — от приёма топлива до программ лояльности.

### Продукты экосистемы

![Архитектура TradeSuite](tradeframe-screens/tradesuite-architecture.png)
*Структура экосистемы TradeSuite*

| Продукт | Назначение | Основные функции |
|---------|------------|------------------|
| **TradeFrame** | Управление сетью АЗС | Мониторинг продаж, резервуаров, оборудования. Ценообразование, сменные отчёты, аналитика |
| **TradeCorp** | Корпоративные клиенты | Топливные карты, лимиты, кредитные линии. Личный кабинет для организаций |
| **TradeBonus** | Программа лояльности | Накопление и списание бонусов. Акции, скидки, персональные предложения |
| **TradeGate** | Онлайн-заказы | Приём и обработка заказов от агрегаторов (Яндекс.Заправки, СберЗаправки и др.) |

**TradeFrame** — центральный продукт экосистемы. Именно в нём сходятся данные со всех станций сети: транзакции, остатки топлива, состояние оборудования. Остальные продукты расширяют возможности:

- **TradeCorp** добавляет работу с корпоративными клиентами — выпуск топливных карт, установка лимитов по объёму или сумме, ведение кредитных договоров
- **TradeBonus** реализует программы лояльности для розничных покупателей — начисление бонусов за покупки, проведение акций, персонализация предложений
- **TradeGate** обрабатывает онлайн-заказы от топливных агрегаторов — клиент оплачивает заправку в приложении (Яндекс.Заправки, СберЗаправки), заказ поступает на станцию, топливо отпускается без дополнительной оплаты

### Типы торговых точек

| Код | Тип точки | Назначение |
|-----|-----------|------------|
| **АЗС** | **АЗС с оператором** | Классическая станция с персоналом |
| **ААЗС** | **Автоматическая АЗС** | Без персонала (включая контейнерные) |
| **АГЗС** | **АГЗС** | Газовая станция (пропан-бутан) |
| **ТСО** | **Терминал самообслуживания** | Модуль к АЗС или ядро ААЗС |

> **Подробнее о терминалах самообслуживания:** см. [TERMINAL_TCO_GUIDE.md](TERMINAL_TCO_GUIDE.md)

### 3.6 Купоны на остаток топлива

![Купоны](tradeframe-screens/07_coupons.png)
*Журнал выданных купонов на остаток топлива*

**Что такое купон?**

Купон — это способ вернуть клиенту неиспользованный остаток оплаты на терминале самообслуживания. Если клиент оплатил наличными, но топливо не поместилось в бак полностью, терминал не может выдать сдачу деньгами. Вместо этого печатается купон на остаток.

**Как это работает:**

| Этап | Описание |
|------|----------|
| 1. Оплата | Клиент вносит наличные (например, 1000 ₽) |
| 2. Заправка | Бак заполнился на 850 ₽, остаток 150 ₽ |
| 3. Купон | Терминал печатает купон на 150 ₽ |
| 4. Использование | Клиент заправляется по купону без оплаты |

**Условия использования:**
- Срок действия: **7 дней** с момента выдачи
- Место: только на **том же терминале**, где был выдан
- Оплата: не требуется, топливо по купону бесплатно (уже оплачено)

**Данные в журнале:**
- Номер купона
- Дата и время выдачи
- Сумма остатка
- Статус (активен / использован / просрочен)
- Дата использования (если был использован)

## 5. Система уведомлений

### 5.1 Настройки уведомлений

![Настройки уведомлений](tradeframe-screens/11_notifications.png)
*Настройки Telegram, Email, режим "Не беспокоить"*

**Каналы уведомлений:**
- **Telegram Bot** (@TradeFrameDW_Bot) — мгновенные уведомления
- **Email** — для тех, кто предпочитает почту

**Автоматические проверки:**

| Проверка | Частота | Описание |
|----------|---------|----------|
| Критический уровень топлива | Каждые 4 часа | Резервуар <10% |
| Оборудование offline | Каждые 30 минут | ТРК, терминал не отвечает |
| Переполнение купюроприемника | Каждые 6 часов | Заполнение >85% |
| Незакрытые смены | Ежедневно в 01:00 | Смена не закрыта |

**Приоритеты:**
- 🔴 **Критичное** — немедленные действия
- 🟠 **Высокое** — важные события
- 🟡 **Среднее** — информационные
- 🔵 **Низкое** — общие уведомления

## Безопасность

### Меры защиты

- **JWT токены** с ограниченным сроком действия (1 час)
- **Хеширование паролей** (SHA-256)
- **Ролевая модель доступа** (RBAC) — 40+ разрешений
- **Row Level Security** — изоляция данных на уровне БД
- **Журнал аудита** — логирование всех действий

### Соответствие стандартам

- ✅ 152-ФЗ "О персональных данных" (Россия)
