## Быстрый старт

1. Откройте [USER_GUIDE.md](USER_GUIDE.md)
2. Следуйте разделу "Начало работы"
3. Используйте скриншоты для наглядности

## Для кого это руководство

- 👤 **Пользователи** — сотрудники АЗС, менеджеры, администраторы
- 📚 **Новички** — новые пользователи системы
- 🔧 **Администраторы** — настройка уведомлений и рассылок

## Основные разделы руководства

1. **Авторизация** — вход в систему
2. **Торговые сети** — аналитика продаж, операции, прогнозы
3. **Торговая точка** — цены, резервуары, оборудование
4. **Уведомления** — настройка Email и Telegram уведомлений
5. **Рассылка сообщений** — отправка новостей пользователям
6. **FAQ** — часто задаваемые вопросы
