🔍 Отладка фильтра способов оплаты

❌ Проблема

Фильтры способов оплаты не работают - при выборе любого способа оплаты не отображаются транзакции.

🔍 План диагностики
  1. Проверить консоль браузера на странице операций
  2. Найти отладочную информацию фильтра оплаты
  3. Сравнить нормализованные значения
  4. Проверить логику сравнения в коде
🧪 Тестовые действия

1. Открыть страницу операций с консолью:

2. Инструкции по проверке:

1. На странице операций выберите любой способ оплаты в фильтре 2. В консоли найдите сообщения "🔍 Отладка фильтра оплаты:" 3. Проверьте значения: - Исходный способ оплаты записи - Нормализованный способ записи - Выбранный способ в фильтре - Нормализованный выбранный - Совпадение (true/false)

📊 Результат анализа:

🛠️ Возможные причины
  1. Проблема нормализации - функция normalizePaymentMethod возвращает разные значения
  2. Проблема с регистром - разные варианты написания
  3. Логическая ошибка - неправильное условие в фильтре
  4. Проблема с данными - пустые или неожиданные значения
💡 Предварительный анализ кода

Текущая логика фильтрации:

// Фильтр по виду оплаты if (selectedPaymentMethod !== "Все") { const recordNormalized = normalizePaymentMethod(record.paymentMethod); const selectedNormalized = normalizePaymentMethod(selectedPaymentMethod); if (recordNormalized !== selectedNormalized) return false; }

Функция нормализации включает:

const normalizePaymentMethod = (paymentMethod: string): string => { if (!paymentMethod) return '-'; const method = paymentMethod.toLowerCase(); // Наличные if (['cash', 'наличные'].includes(method)) return 'Наличные'; // Банковские карты if (['bank_card', 'карта', 'сбербанк', 'card', 'credit_card', 'debit_card'].includes(method)) return 'Банк. карты'; // Топливные карты if (['fuel_card', 'топливная_карта', 'fleet_card', 'нкт'].includes(method)) return 'Топл. карты'; // Онлайн заказы и мобильные платежи if (['online_order', 'мобил.п', 'мобильная', 'мобильная оплата', 'mobile', 'qr'].includes(method)) return 'Онлайн'; return paymentMethod; // Возвращаем исходное значение };
