🐛 Отладка: журнал цен пустой

❌ Проблема

Журнал истории цен пустой - API не возвращает данные

Возможные причины:

  • API возвращает пустой массив
  • API возвращает ошибку
  • Неправильная структура ответа
  • Неверные параметры запроса
  • Нет данных за период с 01.09.2025
🔍 Шаги диагностики
  1. Откройте страницу цен
  2. Откройте консоль браузера (F12)
  3. Нажмите "История цен"
  4. Найдите в консоли логи:
    📅 Загрузка журнала цен 🗂️ STS API: getPriceSchedule called ✅ STS API: Журнал цен получен 📊 STS API: Обрабатываем данные
📋 Что искать в логах

1. Проверьте структуру ответа:

✅ STS API: Журнал цен получен { type: "object" | "array", isArray: true/false, data: {...} }

2. Проверьте обработанные данные:

📊 STS API: Обрабатываем данные { count: 0, ← ЕСЛИ 0, то данных нет! sample: [] }

3. Проверьте параметры запроса:

📅 STS API: Запрос журнала цен { networkNumber: "15", stationNumber: "4", dateFrom: "2025-09-01T00:00:00", fullEndpoint: "/v1/pos/schedule/prices/4?system=15&dt=2025-09-01T00%3A00%3A00" }
🧪 Возможные исправления

Если count: 0 - нет данных:

  • Попробуйте другую дату: "2024-01-01T00:00:00"
  • Проверьте правильность номера сети и станции
  • Возможно, данных за этот период действительно нет

Если ошибка в запросе:

  • Проверьте настройки STS API в /settings/external-database
  • Убедитесь, что токен обновляется
  • Проверьте доступность API
