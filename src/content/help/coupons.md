# Купоны

Раздел **«Купоны»** управляет купонами/талонами в рамках сети.

## Что можно

- Просмотреть выпущенные купоны и их статус.
- Отследить использование.
- Отфильтровать по периоду и состоянию.

## Статусы

| Статус | Значение |
| --- | --- |
| Активен | Можно использовать |
| Погашен | Уже использован |
| Аннулирован | Выведен из обращения |

> Если купон не принимается на точке при активном статусе — проверьте связь точки и сообщите в
> поддержку.
