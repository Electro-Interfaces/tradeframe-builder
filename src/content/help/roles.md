# Роли и права

Раздел **«Роли»** определяет наборы прав, которые затем назначаются пользователям.

## Как устроены права

Право — это пара «раздел + действие» (например, «Цены: изменять», «Пользователи: создавать»).
Роль объединяет нужные права. Пользователь получает права через назначенные ему роли.

## Создание роли

1. Задайте название роли (например, «Оператор», «Менеджер сети»).
2. Отметьте разрешённые действия по разделам.
3. При необходимости задайте область по умолчанию (сеть/точка).
4. Сохраните и назначайте роль пользователям в разделе **«Пользователи»**.

## Принципы

- **Минимум прав** — выдавайте только то, что нужно для работы.
- **Роль = должность** — удобнее вести роли под типовые должности, чем настраивать каждого
  пользователя отдельно.
- Изменение прав роли применяется ко всем пользователям с этой ролью.

> Кто и что менял по ролям и пользователям — видно в **«Журнале аудита»**.
