# Остатки топлива

Раздел **«Остатки»** сводит текущие остатки топлива по точкам сети — удобно для контроля «где
сколько» и планирования поставок.

## Что показывает

- Остатки по видам топлива и резервуарам.
- Свободную ёмкость для приёмки.
- Сводку по сети с детализацией до точки.

## Особенности

- Первый заход в раздел может занять несколько секунд: данные собираются из системы АЗС по
  точкам. Дальше работает быстрее (кэш).
- Детальные уровни по конкретной АЗС смотрите в разделе **«Резервуары»**.

> Если по точке остатки не приходят — вероятно, проблема со связью АЗС (см. **«Оборудование»**).
