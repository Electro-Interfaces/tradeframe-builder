# Операции и транзакции

Раздел **«Операции»** показывает транзакции и продажи по сети: заправки, оплаты, возвраты.

## Что внутри

- Лента операций с фильтрами по точке, виду топлива, типу оплаты, периоду.
- Детали отдельной транзакции.
- Поиск по номеру/сумме.

## Поиск

Поиск по числу работает как **точное совпадение** (например, номер чека или сумма), а не как
подстрока — так быстрее находить конкретную операцию.

> Данные операций приходят из системы АЗС. Свежие операции могут появляться с небольшой задержкой
> синхронизации.
