# Резервуары

Раздел **«Резервуары»** показывает состояние топливных резервуаров выбранной точки: уровни,
объёмы, температуру и состояние датчиков.

## Что показывают карточки

- Текущий уровень и объём топлива по каждому резервуару.
- Свободную ёмкость (сколько можно принять).
- Состояние оборудования измерения.

## Два регистра остатка

По резервуару может отображаться **книжный** (учётный) и **реальный** (по датчику) остаток —
это разные величины, и их **не следует смешивать**:

| Регистр | Что это |
| --- | --- |
| Книжный | Расчётный остаток по приходам/расходам |
| Реальный | Замер по уровнемеру/датчику |

Расхождение между ними — нормальный повод для инвентаризации, а не ошибка отображения.

> Данные приходят из системы мониторинга АЗС и обновляются автоматически. Если резервуар «пустой»
> по датчику, но топливо есть — проверьте оборудование измерения.
