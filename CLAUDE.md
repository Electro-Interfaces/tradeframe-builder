# TradeFrame (TF)

## Назначение

Проект TradeFrame — Vue + Supabase + Node.js.

## Стек

- **Frontend:** React 18 + Vite + Tailwind + shadcn/ui
- **Backend:** Node.js (Express) + Supabase

## Запуск dev-окружения

**Порядок запуска: сначала бэкенд, потом фронтенд.**

Если порты 3001/3000 заняты — убить процессы перед запуском:
```powershell
# Проверить занятые порты
netstat -ano | findstr ":3000 :3001" | findstr "LISTENING"
# Убить процесс по PID
taskkill //PID <PID> //F
```

### 1. Бэкенд (порт 3001)
```bash
cd server && node index.js
```
- Express-сервер, прокси для STS/TradeCorp/MSTO API
- Telegram-бот, планировщик уведомлений
- Конфиг: `server/.env`

### 2. Фронтенд (порт 3000)
```bash
npm run dev
```
- Vite dev-сервер с HMR
- Проксирует `/api/*` на бэкенд :3001 (через vite.config.ts)

## Доступ к серверам

При подключении к удалённым серверам по SSH: (1) сначала проверь, что порт 22 открыт, (2) используй sshpass или WSL для неинтерактивного SSH при необходимости, (3) помни, что кеширование разрешений Claude Code может блокировать SSH-команды — если SSH постоянно отклоняется, сообщи пользователю о необходимости перезапуска сессии.

## Рабочий язык

Основной язык общения — русский. Пользователь работает в русскоязычной среде, использует русскую терминологию и ожидает ответов на русском, если не указано иное.
